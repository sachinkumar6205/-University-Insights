1. Study MBBS Abroad Landing Page

This project is a responsive and SEO-optimized landing page for promoting MBBS programs abroad. It features an engaging layout with country listings, program benefits, a lead generation form, and user tracking integrations.

2. Features

* Hero Section: Catchy headline with a "Apply Now" call-to-action button.
* Why Study MBBS Abroad Section: Highlights key benefits of studying abroad.
* Top Countries: Lists countries such as Russia, Uzbekistan, and more.
* Admission Process & Eligibility: Step-by-step guide for applicants.
* Lead Generation Form: Captures user details like name, email, phone, and preferred country.
* Responsive Design: Mobile-friendly layout using Tailwind CSS.
* SEO Optimized: Includes meta tags and fast-loading features.
* Google Analytics and Facebook Pixel Integration: Tracks user engagement and conversions.

3. Technologies Used

* HTML: To structure the page content.
* Tailwind CSS: For styling and creating a responsive design.
* JavaScript: For form validation and interactivity.
